# Landing page photos

The landing page ships with illustrated portraits of smiling people. To use real photos instead, add
licensed images (you own them, or have written permission from the people shown) to `public/landing/`:

`hero-1.jpg`, `hero-2.jpg`, `hero-3.jpg` (hero collage), `about-1.jpg`, `about-2.jpg`, `about-3.jpg` (cards).

Each photo covers its illustration automatically. Any missing file keeps the illustration. Use portrait-ish
images around 900px wide, under 200 KB each. Never use photos of real people without consent.
